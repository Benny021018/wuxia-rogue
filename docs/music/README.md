# 天魔劫配樂設計：主題曲與綠林山寨

兩首曲子都是「程式化樂譜」：動機、和聲、段落、聲部全部寫在 `tools/music/compose.py`，渲染、分析也都用程式完成，可以重現、可以改。

| 曲目 | 調式／速度 | 長度 | 遊戲中 |
|---|---|---|---|
| 天魔劫・主題曲 | A 羽調式 → 高潮上移到 B，♩=80 | 54 小節，2:46 | 主選單，整首循環 |
| 綠林山寨 | E 羽調式，♩=132 | 44 小節，1:20 | 地圖一，序（4 小節）之後循環 |

## 1. 風格分析

遊戲是韓漫武俠（奈米魔神那一類）：天魔神教、正邪對立、境界突破、一路殺上總壇。畫面是強烈的黑白紅，戰鬥節奏快。配樂取三個方向：

- **中國五聲音階當旋律骨架**：用羽調式（小調色彩的五聲：6 1 2 3 5），二胡、笛子、古箏、琵琶負責「武俠」的辨識度。
- **西方管弦樂＋太鼓當推進力**：弦樂墊底、法國號與長號撐場面、太鼓與締太鼓打節奏，對應韓漫的史詩感與動作感。
- **「魔」的聲音要和「俠」分開**：英雄段落只用五聲與自然小調，天魔出現時加入小二度（弗里幾亞 bII）與三全音，一聽就知道是反派。

## 2. 和聲語法

| 功能 | 和弦（A 調） | 用途 |
|---|---|---|
| 主 | i（Am） | 回家 |
| 史詩循環 | i – bVI – bVII – i（Am F G Am） | 主題段落的骨架，自然小調的英雄感，避免西式導音的「甜」 |
| 半終止 | V（E）、Esus4 → E | 樂句尾端吊住，接下一句 |
| 攀升 | bVI – bVII – v – i，最後 Asus4 → A | 副歌往關係大調色彩走，最後用 A 大三和弦收（皮卡第三度），給「光明」的感覺 |
| 天魔 | i – bII/i（Am → Bb/A），低音持續 A | 小二度摩擦，弗里幾亞色彩 |
| 轉調樞紐 | iv – V – V/ii（Dm E F#） | 橋段把調性推到 B 小調，高潮整段上移全音 |

綠林山寨是同一套語法移到 E：Em C D Em（i bVI bVII i），B 段用 C D Bm Em / Am Bm C D，橋段 Em – F/E（bII）。完整的級數分析在 [`analysis.md`](analysis.md)。

## 3. 動機

簡譜以 1 = C 記（A 羽調式：6 = A）。下加點是低八度，拍數寫在括號。

**英雄動機 x（劍起）**：6̣(1.5) 1(0.5) 2(2) — 主音上行小三度再到四度，像拔劍起勢。
**迴旋 y**：3(1) 5(.5) 3(.5) 2(2) — 在三度附近繞一圈落到 2。

```
主題前句  A4 C5 D5 | E5 G5 E5 D5 | C5 D5 C5 A4 G4 | A4        （Am F G Am）
主題後句  A4 C5 D5 | E5 G5 A5 G5 E5 | D5 E5 D5 B4 | E5        （Am F G E，半終止）
```

**天魔動機**：A2(2) Bb2(1) E2(1) | A2 — 主音 → 小二度 → 三全音下落 → 回主音。低銅管專用，綠林山寨移到 E（E F E B）。

**副歌（攀升）**：A5 G5 | E5 D5 | E5 G5 A5 B5 | C6 A5 | A5 G5 E5 G5 | D5 E5 D5 | D5 E5 | A5 — 長音往上爬到 C6 再收到 A。

**綠林山寨主題**：E5 G5 A5 B5 | G5 A5 G5 E5 D5 … — 開頭就是英雄動機 x 移到 E（E G A），讓地圖曲跟主題曲是同一個主角。

## 4. 結構與聲部

### 主題曲

| 段落 | 小節 | 內容 | 主要聲部 |
|---|---|---|---|
| 序 | 1–8 | 天魔動機出場，鑼聲；後半二胡遠遠吹出英雄動機的頭 | 長號＋大號＋低音提琴（天魔），顫弓弦樂，古箏散音 |
| A 主題 | 9–16 | 二胡獨奏主題（前句＋後句） | 二胡、古箏八分音符琶音、弦樂長音、大提琴 |
| A' 展開 | 17–24 | 主題移到笛子高八度、小提琴原八度；大提琴副旋律跟主旋律反向 | 笛子（倚音）、小提琴、大提琴副旋律、太鼓半拍 |
| B 攀升 | 25–32 | 副歌，轉到關係大調色彩，A 大三和弦收 | 小提琴＋法國號（低八度）、合唱、太鼓八分音符 |
| 橋 天魔 | 33–40 | 天魔動機由法國號正面奏出，轉調準備 | 法國號、長號＋大號、顫弓弦樂、重太鼓、定音鼓滾奏 |
| 高潮 | 41–48 | 上移到 B 小調全奏主題 | 二胡＋小提琴、笛子高八度、合唱、號角和弦、古箏十六分音符 |
| 尾聲 | 49–54 | 二胡獨奏回到英雄動機，古箏刮奏收在 Bm(add9) | 二胡、弦樂淡出、鑼 |

### 綠林山寨（戰鬥循環）

| 段落 | 小節 | 內容 |
|---|---|---|
| 序 | 1–4 | 太鼓開場，琵琶與低音弦樂頓弓進來，古箏刮奏 → **循環從第 5 小節開始** |
| A 山道 | 5–12 | 笛子主奏山寨主題 |
| A' 寨門 | 13–20 | 二胡接主題，笛子在高音吹副旋律（守在和弦三度／延伸音） |
| B 校場 | 21–28 | 二胡主奏，琵琶改十六分音符並在休止處應答，鼓更密 |
| 橋 黑風 | 29–36 | 鼓轉半拍，低銅管奏天魔動機（E F E B），二胡長音哭腔 |
| A'' 聚義廳 | 37–44 | 全奏：笛子＋二胡＋小提琴低八度，號角長音，回到 A |

### 聲部怎麼排

- **和弦墊底**：`theory.voice()` 在指定音域裡列出所有和弦音組合，挑「各聲部移動距離總和最小」的那組，並對平行五度／八度加重罰分。兩首曲子共 92 個和弦，平行五八度與聲部交錯都是 0。
- **副旋律**：`theory.guide_line()` 每個和弦取最近的三度／五度／延伸音，盡量級進，並跟主旋律走反方向。
- **低音**：取根音或 slash 低音，跟前一音最近的八度；B 段之後加上切分節奏。
- **琶音／固定音型**：古箏、琵琶都從和弦的音階梯取音（`Chord.ladder()`），換和弦時自動跟著走。
- **力度曲線**：主題曲序 −7 dB → 高潮 +2.5 dB，再在尾聲回落；量測各段 RMS：序 −20.5、A −17.8、A' −16.3、高潮 −13.6、尾聲 −18.5 dB。

## 5. 製作流程

```
python3 tools/music/compose.py    # 樂譜 → docs/music/*.mid
python3 tools/music/analyze.py    # music21：級數、聲部檢查、音域、旋律契合度 → analysis.md、*.musicxml
python3 tools/music/render.py     # 渲染 → assets/audio/music/*.ogg，並把循環點寫回 data/music.csv
```

- **音色**：GeneralUser GS v2.0.3（S. Christian Collins，免費、可商用），用 tinysoundfont 渲染。音色庫 32 MB，不放進 repo，從 https://github.com/mrbumpy409/GeneralUser-GS 下載後設定 `MUSIC_SF2`。
  - 二胡（Fiddle）：5.6 Hz 揉弦、0.16 秒後才起揉，7 度以內的連音會滑音
  - 笛子（Flute）：輕揉弦，長音前加上方倚音
- **打擊樂**：太鼓、大太鼓、締太鼓、梆子、鈸、鑼全部用 numpy 合成，每一擊微調 ±2.5% 音高。
- **殘響**：合成的立體聲脈衝響應（主題曲 RT60 2.6 秒、地圖曲 1.7 秒），高頻衰減較快。
- **母帶**：高通 28 Hz → 壓縮 1.8:1 → 響度正規化到 −16 LUFS → 限幅（峰值 ≤ −1.2 dBFS），數字在 [`render_stats.json`](render_stats.json)。
- **循環**：地圖曲把結尾之後的殘響折回循環起點，接縫處的樣本跳動 0.065，小於附近正常波形變化（0.28），不會有爆音。
- **樂譜**：`*.musicxml` 可以用 MuseScore 4 開啟，含旋律聲部與和弦符號；`*.mid` 可以丟進任何 DAW 換成更好的音色。

## 6. 遊戲接入

- `scripts/music.gd`（自動載入 `Music`）：兩個播放器交叉淡入淡出，`Music.play("menu")` 或 `Music.play(map_id)`。
- `data/music.csv`：檔案、音量、循環點、淡入秒數。沒有設定的地圖會把音樂淡出（暗月樓之後的地圖還沒有配樂）。
- 冒煙測試檢查主選單與地圖一的配樂有在播、有循環、循環點正確。
