# 綠林山寨：冷墨與刀光

## 參考與取捨

[《奈米魔神》WEBTOON 官方頁面](https://www.webtoons.com/en/action/nano-machine/list?title_no=4344) 的主視覺以深青背景托住深色長髮，以一條亮刀面切開構圖，紅衣與眼部暖光集中在人物身上。前幾話縮圖的衣膚則相對沉靜。這是對封面與公開縮圖的觀察，不能代表全書每個場景的固定配色。作品將武俠門派與未來技術並置；本作保留山寨材質和身分差異，把異常的冷光留給刀氣，而不在木牆上加科幻燈帶。

## 在遊戲內怎麼看

- **人物**：墨靛、灰青和皮革占大面積，腰帶留一條朱砂色。弓手收窄衣身讓弓臂看得清，盾手保留盾面，血刀客用暗紅衣袍，寨主用深甲與寬肩。暗邊沿人物外輪廓，肩、臉和刃口保有亮面。受擊仍左右晃動並短暫泛紅。
- **武器**：深青鞘與握柄、舊銅刀鐔、冷銀刃。第一人稱輪廓優先於細紋。新太刀的 Smart Mesh 草稿偏直，在 Blender 修窄並補上漸進弧度，獨立做鞘；前一批的 HD 草稿未用於遊戲。
- **地圖**：灰木、青灰地面與分層山影讓出人物對比。遠處看得出箭樓和寨門的形狀，靠近才看得見橫撐、輪子和碑緣。火盆是暖色視線提示。
- **特效**：近戰弧光外緣冷白，內側僅在中段疊一筆墨色殘影，兩端收細。弧線仍依實際攻擊半徑生成，不因換色改變判定。敵方預警、盾擋與毒傷沿用原本語意色。

## 資產與驗收

這一批全部用 Tripo Studio **Smart Mesh P2.0** 單件生成，匯出 FBX，再進 Blender。來源資產保留在帳戶；遊戲使用打包好的 GLB，無須登入 Tripo。場景重複物件共用網格，不為每個房間再生成。新角色重新綁到既有動作；遊戲的碰撞與 AI 仍由原腳本負責。無貼圖網格在 Blender 以頂點色上色、Godot 匯入時啟用該材質。這是首輪低面數漫畫風資產，尚未做個別人物的手繪臉部貼圖。

- 武器：W001 青鞘太刀。刀身和握柄來源是 Smart Mesh；鞘是配合新刃形在 Blender 製作的部件。
- 敵人：H01、H02、H03、H07、H08。普通敵人身體約 6,300 三角形；精英與首領身體約 8,600。不含手持道具、輪廓額外繪製成本。
- 物件：寨門、拒馬、箭樓、悟道碑、板車、貨箱、擂台、二樓迴廊、石階、交椅、火盆、木掩體。遊戲版單件約 1,600～2,800 三角形。
- 後續：其餘三圖的專屬敵人與道具、其餘十六把玩家武器、三名可玩角色的獨立人物模型未在此批替換。地板牆面、碰撞、區域標記、傳送陣與攻擊特效仍使用引擎材質、幾何或動畫，不把可變攻擊範圍烘成固定網格。
