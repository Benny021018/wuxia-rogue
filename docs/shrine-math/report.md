# 天機輪（悟道碑）數學模型與驗證報告

由 `python3 tools/shrine_math/wheel.py` 產生；所有數字在 `results.json`。

## 1. 規則與計算口徑

- 3 軸 × 3 列，中線一條。三個八卦＝**八卦歸一**；三軸同門（八卦百搭）＝**門派共鳴**；前兩軸同門＝**門派感應**。
- 畫面任意位置 3 個悟（每軸最多一個）＝**頓悟**，送 3 次免費參悟，可再觸發。
- 天機回報：一次參悟次數期望拿到的候選稀有度預算總和（凡品 1、良品 2.2、神兵 5、絕世 12），含頓悟的免費參悟；不含幸運、天機保底與門派權重。

## 2. 精確理論（窮舉 8,000 種停輪組合）

| 項目 | 數值 |
|---|---:|
| 門派感應 | 21.000% |
| 門派共鳴 | 6.000% |
| 八卦歸一 | 0.050% |
| 有任一連線效果 | 27.050% |
| 頓悟觸發 p | 2.700%（精確 27/1000） |
| 一次參悟次數的期望總轉數 1/(1−3p) | 1.0881 |
| 一轉的期望候選預算 | 6.0322 |
| **天機回報（一次參悟次數）** | **6.5639**（精確 2991973/455824） |
| 天機回報的標準差 σ | 3.7205 |

### 回報拆分

## 3. 蒙地卡羅驗證

- 500,000 次參悟次數，分 5 個種子（100–104）。
- 天機回報 6.5659，95% CI [6.5556, 6.5762]，z = +0.39；5/5 個種子的 CI 涵蓋理論值。
- 頓悟觸發率 0.02684（理論 0.02700），z = -0.71。
- 停輪均勻性卡方：第 1 軸 p = 0.495、第 2 軸 p = 0.026、第 3 軸 p = 0.439
- 樣本量：要讓天機回報有 ±1% 相對精度（95%），需要 n = (1.96σ / 0.01μ)² = 12,343 次。

## 4. 與遊戲實作對照

- `tests/wheel_golden.json`：609 組停輪位置（隨機 400 組＋全部八卦歸一與頓悟盤面）與正確結果。
