# 天機輪（悟道碑）數學模型與驗證報告

由 `python3 tools/shrine_math/wheel.py` 產生；所有數字在 `results.json`。

## 1. 規則與計算口徑

- 3 軸 × 3 列，中線一條。三個八卦＝**八卦歸一**；三軸同門（八卦百搭）＝**門派共鳴**；前兩軸同門＝**門派感應**。
- 畫面任意位置 3 個悟（每軸最多一個，由輪帶間距保證）＝**頓悟**，送 3 次免費參悟，可再觸發。
- 效果：門派感應＝1 張候選指定門派；門派共鳴＝3 張都是該門派武學、稀有度升 1 階；八卦歸一＝1 張必出絕世、其餘升 1 階。
- **天機回報**（RTP 的類比）：一次參悟次數期望拿到的候選稀有度預算總和（凡品 1、良品 2.2、神兵 5、絕世 12），含頓悟的免費參悟。
- 計算邊界：起始狀態（尚未習得武學、欄位未滿），不含幸運、天機保底、門派權重、額外候選與角色保證效果。這些會改變實際分布，屬於平衡模擬（`tools/balance/sim.py`）的範圍。

## 3. 差異分析：v1 模型高估了門派共鳴

v1 把門派共鳴的三張候選當成「各自獨立升一階」，一轉期望預算 = 3 × E[升階後預算]。但遊戲的 `_sect_candidate` 是從**同一門派**的武學池**不重複**抽，該稀有度抽完就往下退。例如少林只有 1 門神兵、1 門絕世，第二張再抽到神兵就會退成良品。

| 項目 | v1（獨立升階） | v2（門派池不重複抽） | 差異 |
|---|---:|---:|---:|
| 門派共鳴一轉期望預算 | 12.2903 | 11.4732（加權平均） | -0.8171 |
| 門派共鳴的回報貢獻 | 0.3999 | 0.3509 | -12.3% |
| 天機回報 | 6.5639 | 6.5105 | -0.81% |

怎麼發現的：v1 的驗證只比對了「轉輪判定」和「觸發機率」，兩者都 100% 一致，卻沒有驗證「結果套到候選之後的稀有度」。審查 `Game.roll_choices()` 時注意到門派候選有退階邏輯，於是在冒煙測試補上遊戲實抽的對照（第 5 節）：各門派實抽 4,000 次（種子 20261112），對 v2 的 z 值在 −0.90 到 +1.23 之間，對 v1 的 z 值是 −6.96 到 −16.39，確認 v1 錯了。總回報只差不到 1%，光看總數的蒙地卡羅很難發現，所以要拆到每個結果分別對照。

## 4. 蒙地卡羅（驗證分支過程與頓悟再觸發）

- 500,000 次參悟次數，分 5 個種子（100–104）。
- 天機回報 6.5121，95% CI [6.5021, 6.5221]，z = +0.31；5/5 個種子的 CI 涵蓋理論值。
- 頓悟觸發率 0.02684（理論 0.02700），z = -0.71。
- 停輪均勻性卡方：第 1 軸 p = 0.495、第 2 軸 p = 0.026、第 3 軸 p = 0.439（3 次檢定，Bonferroni α = 0.0167）。
- 樣本量：要讓天機回報有 ±1% 相對精度（95%），需要 n = (1.96σ / 0.01μ)² = 11,815 次。
- 這一段的模擬和理論共用判定與期望預算，只能驗證「免費參悟與再觸發」的推導；判定與候選的正確性由第 5 節對遊戲實作驗證。

## 5. 與遊戲實作對照（冒煙測試 `_check_wheel`）

模型（Python）和遊戲（GDScript）分別實作，各自先驗證，再互相對照：

| 檢查 | 做法 | 驗收條件 |
|---|---|---|
| 逐盤面判定 | `tests/wheel_golden.json` 609 組停輪（隨機 400 組＋全部八卦歸一與頓悟盤面），讓 `Game.wheel_eval()` 判定 | 100% 相同 |
| 機率公示 | 遊戲內 `Game.wheel_odds()` 自己窮舉 | 與 results.json 的精確值相等 |
| 遊戲亂數 | `Game.wheel_spin()` 實轉 20,000 次 | 頓悟率、共鳴率的 z 絕對值 ≤ 3.29 |
| 候選稀有度 | 用 `Game.roll_choices()` 對一般、八卦歸一、各門派共鳴各實抽 4,000 次，算平均預算 | 每項 z 絕對值 ≤ 3.29（對照第 2 節的期望預算） |
