# 天魔劫音效設計

音效全部由 `tools/sfx/make_sfx.py` 程式合成；有旋律的提示音（鐘琴、古箏、銅管、合唱）用 GeneralUser GS 音色庫，太鼓與鑼沿用配樂的合成器，所以音效和配樂是同一套聲音。播放設定在 `data/sfx.csv`，播放器是 `scripts/sfx.gd`（自動載入 `Sfx`）。

```
python3 tools/sfx/make_sfx.py           # 重新產生全部音效（約 3 秒）
python3 tools/sfx/make_sfx.py hit_low   # 只重做一個
```

## 1. 盤點方法

逐一走過遊戲裡會發生的事件（玩家輸入、命中、敵人行為、區域流程、介面操作、天機輪、經脈），每個事件問三件事：玩家需不需要靠聲音得知它發生了？需不需要知道方向（3D 定位）？會不會在短時間內大量重複（需要變體與聲部上限）？結果是 69 個音效 id：65 個獨立合成（共 79 個檔案，含變體），另外 4 個（敵人揮擊、敵方弓手拉弓／放箭、投擲）沿用玩家的音效再變調。

- **需要定位**（敵人起手、弓手拉弓、毒瓶、範圍攻擊預警）：用 3D 播放器，玩家聽得出危險從哪邊來，配合遠程 AI 的起手給反應時間。
- **大量重複**（揮擊、命中、腳步、轉輪）：多個變體輪替＋音高隨機 ±4～10%＋最短間隔與同時聲部上限，避免機關槍感。
- **一次性事件**（破陣、突破、八卦歸一）：較長、較華麗的提示音，用音色庫做出旋律，跟配樂同一個調性（A 羽調式）。

## 2. 打擊感

| 要素 | 做法 | 數值（data/feel_config.csv） |
|---|---|---|
| 頓幀 | 命中瞬間 `Engine.time_scale` 壓到 0.04，以真實時間計時後恢復；多段命中只延長到上限 | 一般 45 ms、重兵器 75 ms、暴擊 90 ms、擊殺 110 ms，上限 140 ms |
| 震屏 | trauma 模型：震動量疊加、強度＝trauma²、每秒衰減；位移＋翻滾，三個頻率正弦疊加的平滑雜訊 | 一般 0.16、重 0.28、暴擊 0.32、擊殺 0.38、受傷 0.45×傷害比例、爆炸 0.6 |
| 受擊閃白 | 全白覆蓋 45 ms → 轉紅 → 淡出；暴擊更亮 | hold 0.045 s、fade 0.12 s |
| 擊退＋形變 | 真實位移（速度逐幀衰減，精英 45%、首領 12%）；模型先壓扁再拉長再彈回；擊殺時屍身被打飛、傾倒、縮小後消失 | 擊退 3.2 m/s×武器權重、暴擊 ×1.5；壓扁 22%；打飛 0.32 s／1.6 m |
| 粒子＋跳字 | 命中噴火花（沿打擊方向拉長）＋血墨滴（受重力）；擊殺加大量血墨與煙塵；跳字先放大彈出再上飄淡出，暴擊更大且帶「!」 | 火花 14／暴擊 26、擊殺 40 |
| 分層音效 | 低頻重擊（hit_low）＋中頻碎裂（肉身 hit_mid_flesh／盾甲 hit_mid_metal）＋高頻風聲（hit_high）；暴擊加 crit_sting、擊殺加 kill_boom；武器越重，低頻越大聲、整體音高越低 | 見下表音量 |

一次出招（或一支箭）不論打中幾個敵人，只觸發一次頓幀與一組分層音效，多目標時不會疊成噪音。玩家受傷則是畫面邊緣紅光＋震動＋悶擊聲。設定裡可以關掉頓幀、把畫面震動調到 0、關掉傷害跳字。

## 4. 設定

設定頁（主選單與暫停選單都有，稿見 `docs/ui-drafts/15-settings.svg`）：主音量、音樂（預設 30%）、音效（預設 50%）、滑鼠靈敏度、畫面震動、頓幀、傷害跳字、全螢幕。預設值與範圍在 `data/settings_config.csv`，玩家改過的值存在 `user://settings.cfg`。音量透過 Music／SFX 兩條匯流排套用，調整即時生效。
